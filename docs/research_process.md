# 研究流程

1. 从 `data/raw/news/YYYY/MM/YYYYMMDD.csv` 的未标注银行新闻出发。
2. 通过抽样、AI试标、反馈争议改进规则。规则格式见 `docs/annotation/rules_final.md`；真实批次、标签与裁决不随代码发布。
3. 固定规则，形成文章级隔离的训练、验证、测试集。相关性数据保留正反例，情绪数据只保留相关且正负方向明确的样本。
4. 相关性保留第一轮模型；情绪最终采用目标银行提及token末层平均池化和温和平衡采样，单条权重为类别频数的负二分之一次方。
5. 用正式模型标注日度新闻，另为每个原始文章—银行组合提取一个768维向量。
6. 按交易日生成正负共现网络、文章等权语义均值，PCA在训练期拟合至16维。
7. 从价格、收益率估计日度 ΔCoVaR。
8. 比较无语义和有语义的注意力偏置、扩散模型及基准。

## 数据与复现边界

仓库只包含方法代码。真实新闻、标注样本、数据来源文件、训练权重和所有实验结果均不公开。使用者须自行取得数据和基础模型，并建立匹配的本地输入。

温和平衡采样指单条样本权重正比于其类别频数的负二分之一次方。目标级池化是对可见目标银行提及token的BERT末层向量取平均；长文本沿既定规则截断到512 token。

## 方法限制

- 若输入新闻的日度日期来自月度分配，不能据此解释真实日度事件顺序。
- 文本编码器的训练时间范围应在研究中明确；滚动预测需另行保证时间可得性。
- 滚动估计的风险指标共享大量历史观测，沿用上一期数值是必要对照。
- 新闻共现和注意力表示预测关联，不能单独证明风险因果传染。
- PCA必须仅在预测训练期拟合；不因验证或测试数据调整变换。
