# 银行新闻目标级标注规则

## 标注对象

一条样本对应一段新闻中的一家**目标银行**。同一段新闻提到多家银行时，分别判断每家银行；新闻整体的语气不能直接当作所有银行的情绪。只依据样本中可见的原文，不补充新闻之后发生的事实。

CSV 列顺序为：`NewsContent,BankName,SourceFile,SourceRow,SentenceIndex,分析依据,相关/不相关,积极中性消极`（末列沿用历史列名以保持数据结构兼容）。每条样本只有三种结果：不相关（相关性 `0`，情绪留空）、积极（相关性 `1`，情绪 `1`）、消极（相关性 `1`，情绪 `-1`）。

相关性训练数据保留相关与不相关样本；正式情绪训练、验证、测试文件只保留相关且积极或消极的样本。

这里标注的是**新闻对目标银行传递的情绪**，不是银行真实经营状况，也不是新闻对股价或风险的实际影响。

## 第一步：判断是否与目标银行相关

- `1`：新闻对目标银行的业务、产品、经营、资产质量、治理、监管、声誉、股价、估值、投资者行为、前景或风险提供了可判断相对有利或不利的具体信息、评价或情绪。尚未实现的计划和预期也可以相关，但要区分预期与已发生结果。
- `0`：银行只是名单中的名称、研究员任职单位、缴款或开户行、客户使用的银行卡、其他企业事件中的附属角色，或名称误识别；以及片段虽有该行的静态或程序性事实，但无法判断对目标银行的相对有利或不利方向。
- 只有目标银行的名称，没有可归给该行的信息或评价，判不相关。若新闻明确把群体信息或评价施加于包含目标行的银行群体，可判相关；不能把其他银行的单独事实归给目标行。
- 子公司或境外独立法人是独立主体。只有新闻明确涉及母行自身、母行承担的影响，或明确把情绪指向母行时，才把其信息归给目标母行。
- 基金托管、代销、债权、质押、诉讼等角色若只是在名单中出现，通常不相关；若片段进一步提供目标行的具体业务关系、评价、机会或风险，则相关。
- “中国银行”等名称可能泛指中国的银行业；应根据上下文确认是否为目标银行。

## 第二步：判断新闻对目标银行的情绪

**先确定情绪指向谁，再判断方向。只要片段对目标银行传递出明确的正向情绪，就判积极；传递出明确的负向情绪，就判消极。** 不要求业务已经落地、收益已经实现、风险已经兑现，也不要求出现数字、第三方证明或因果证据。银行自述、报道评价、市场观点和投资者态度都可以构成情绪信号。

### 积极 `1`

新闻对目标银行表达看好、认可、赞扬、优势、机会、有利预期、风险缓解或正面投资态度。例如：报道认为该行新计划有前景；该行自述将改善服务并以积极语气介绍方案；市场预计该行受益；机构建议买入或投资者增持；利润增长或资产质量改善。

**计划、愿景、宣传、静态规模和常规业务动作也可以判积极**：只要新闻的措辞或语境确实在正面呈现目标银行即可，不因“尚未实现”“只有自述”“缺少成效数据”而排除积极判断。依据中应如实写明这是计划、宣传或预期，不写成已实现的事实。

### 消极 `-1`

新闻对目标银行表达担忧、质疑、批评、劣势、压力、不利预期、风险上升或负面投资态度。例如：报道担忧该行未来不良贷款增加；该行产品引发消费者负面体验；市场认为该行竞争力较弱；机构建议卖出或投资者减持；该行被处罚、利润下滑或资产质量恶化。

**风险尚未兑现也可以判消极**：只要新闻确实向读者传递了针对该行的负向情绪。依据中须区分“面临风险／受到质疑”与“已经发生损失／确认违规”，不能把第三方的问题无依据地归咎于银行。

### 弱方向与相对判断

相关样本只保留积极 `1` 与消极 `-1`。先依据明确的评价和结果判断。若只有事实陈述，则判断该事实对目标银行的业务机会、经营稳定、风险敞口、客户利益或市场表现相对有利还是不利，并在分析依据中写明这是相对判断，不得把推断写成已发生的收益或损失。正负信息并存时，依据目标银行在片段中的主导信息判断。若片段仅有名单、历史表格或其他无法归给目标银行的方向性信息，应重新判为不相关 `0`，情绪留空；不得为满足二分类而编造正负方向。

## 多银行、指代与混合信号

先找目标银行及其有效简称，再把评价、变化、数字、预期和投资行为对应到该行。同一片段对不同银行可以有不同标签。出现“该行”等指代时，只在片段内能确认所指银行时使用。银行名与证券、保险、基金等机构名称撞名时先排除误指。

若同一目标银行同时有正负信息，按新闻强调的主导信息及相对影响判断；若两种影响无法区分主次，则按二分类口径判不相关、情绪留空。其他银行的利好或利空不能用来冲淡、覆盖目标行的情绪。

## 填写分析依据

`分析依据`用一句话写明目标银行、新闻传递的方向及触发该方向的原文信息。计划、预测、自述、未证实指控和已发生事实应分别表述，不互相替代。不得仅写“有积极词汇”“模型认为积极”或只重复标签。

无法判断相关主体、指代或主导情绪的样本，按本版三选一口径判不相关，并在依据中说明缺少可归于目标银行的明确方向。不得使用关键词规则、整篇新闻统一标签或模型预测批量代替逐条判断。
